# Бренд KD

Студия продвижения бизнеса: ИИ, автоматизация, соцсети, сайты, вайб-кодинг.

## Стиль

Тёмный интерфейс в духе современных ИИ-инструментов (референс: слайдер «effort» от @ozzyxs1a). Почти чёрный фон, графитовые панели с тонкой рамкой, приглушённый серый текст, розово-фиолетовое свечение на акцентах. Главный интерактивный элемент: слайдер с логотипом в роли ползунка.

## Логотип

Буквы K и D, собранные из линий одной толщины. Внутри D стоит розовый блок, как курсор в терминале: ты пишешь запрос, ИИ делает работу.

| Файл | Где использовать |
|---|---|
| `logo-mark.svg` | Основной, на тёмном фоне, фавикон |
| `logo-mark-light.svg` | Светлый фон |
| `logo-mono.svg` | Печать, штампы, одноцветные носители. Цвет задаётся через `color` |

Свободное поле вокруг знака: не меньше четверти его высоты. Минимальный размер: 24 px.

## Цвета

| Имя | Значение | Роль |
|---|---|---|
| Void | `#0a0a0b` | Фон страницы |
| Panel | `#131315` | Панели, карточки |
| Panel 2 | `#1a1a1d` | Поля ввода, вложенные поверхности |
| Line | `rgba(255,255,255,.08)` | Тонкие рамки |
| Text | `#f2f2f4` | Основной текст |
| Muted | `#8c8c96` | Второстепенный текст |
| Violet | `#8b5cf6` | Свечение, заливка слайдера |
| Pink | `#ff4fa3` | Главный акцент, курсор логотипа |
| Gradient | `#5b34e0` → `#a838cf` → `#d8337f` | Кнопки с белым текстом |

Розовый и фиолетовый используем как свечение и акценты, а не как фон секций. Текст на градиентных кнопках только белый.

## Шрифты

- **Onest** (400, 500, 600, 700) - всё: заголовки (600, плотный трекинг -0.03em) и текст. Есть кириллица.
- **JetBrains Mono** - только для кода и консольных блоков.

Подключены в `tokens.css`.

## Кнопки

Для связи и главных действий: глянцевые, с переливающимся градиентом, светлой полосой сверху и бегущим бликом. Основная розово-фиолетовая, вторичная графитовая. Реализация в `site/index.html` (`.btn-glossy`, `.btn-pink`, `.btn-graphite`).

## Подключение в новый сайт

```html
<link rel="stylesheet" href="../brand/tokens.css">
```

Дальше используйте переменные: `var(--kd-pink)`, `var(--kd-panel)`, `var(--kd-font-body)` и так далее.

## Тон текста

Коротко, по делу, без канцелярита и штампов. Юмор умеренный. Только короткое тире (-).
